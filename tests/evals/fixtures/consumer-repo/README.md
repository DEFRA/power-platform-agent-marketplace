# Abc Cases

Case management for an inspection service. A Case belongs to an Applicant and can have Inspections.

- `src/Solutions/AbcCases` is the unpacked Dataverse solution (publisher prefix `abc`).
- `src/Plugins` holds the plug-in project and its unit tests.
- `src/WebResources` holds the TypeScript form scripts and their tests.
- `tests/Acceptance` holds the Gherkin features and step bindings.
- `docs/adr` holds the architecture decision records.
- `logs` holds captured test output.
